- Core Python concepts (data types, loops, conditionals)

These assignments helped me move from writing basic programs to developing structured, real-world mini applications.


## Restaurant Billing System – Python Project

This project is a console-based Restaurant Billing System developed using Python.
It simulates a real-world restaurant order and bill generation workflow, including order entry, total calculation, and optional bill file saving.
